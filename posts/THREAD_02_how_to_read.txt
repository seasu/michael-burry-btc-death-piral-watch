如何閱讀 BTC Death Spiral Watch 的每日報告？

1/
每天 09:00（台北時間）自動發出監測報告，格式固定，30 秒看完重點。這篇教你怎麼讀。

2/
Price = BTC 現貨價格（CoinGecko）
後面 % 是跟 24h 前比較。

> +3% 正常上漲
±3% 盤整
-3~-7% 修正
-7~-15% 急跌警戒
< -15% 崩盤等級

3/
OI = 未平倉合約總值（CoinGecko Derivatives）
代表市場上還有多少槓桿部位。OI↓ = 強平或減倉。

> +5% 槓桿快速增加
+1~+5% 健康增長
±1% 穩定
-1~-5% 去槓桿中
< -5% 大規模清算

4/
Funding Rate = 多空互付費率（CoinGecko Derivatives）
正值＝偏多，負值＝偏空，越極端越危險。

> 0.03% 多頭極擁擠（Burry 泡沫訊號）
0.01~0.03% 偏多
±0.01% 中性
-0.01~-0.03% 偏空
< -0.03% 極度恐慌

5/
Verdict 判讀規則：

Price↓ + OI↓ → Spiral Risk ↑
→ 去槓桿螺旋風險升高

Price↑ + OI↑ → Spiral Risk ↓
→ 槓桿健康增長

其他 → Neutral
→ 訊號混合，暫無明確方向

6/
接近 Burry 泡沫崩塌的條件：

1. OI 歷史高位（槓桿泡沫已形成）
2. Funding > 0.03%（多頭極度擁擠）
3. 價格開始跌 > 5%（觸發清算）
4. OI 急降 > 5%（連鎖清算啟動）
5. Funding 急轉負值（貪婪→恐慌）

7/
每則貼文附 GitHub 審計連結，指向當天原始數據 JSON，可自行驗證。

Dashboard 提供即時圖表 + 多語言 + 時區切換。

這不是投資建議，是自動化風險監測工具。有問題歡迎留言。
